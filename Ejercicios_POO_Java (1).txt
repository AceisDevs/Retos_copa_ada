1) CUENTA BANCARIA CON ENCAPSULAMIENTO
--------------------------------------------------------------
Nivel: Fácil

ENUNCIADO:
Crea una clase llamada CuentaBancaria que permita manejar el saldo de una persona de forma segura.
Debe tener:
- Un atributo privado saldo.
- Métodos depositar(double) y retirar(double) que validen los montos.
- Un método getSaldo() que devuelva el saldo actual.
- En el método main, demuestra su uso realizando operaciones.

CÓDIGO:
---------------------------------
public class CuentaBancaria {
    private double saldo;

    public CuentaBancaria(double saldoInicial) {
        this.saldo = saldoInicial;
    }

    public double getSaldo() {
        return saldo;
    }

    public void depositar(double monto) {
        if (monto <= 0) throw new IllegalArgumentException("Monto inválido");
        saldo += monto;
    }

    public void retirar(double monto) {
        if (monto <= 0 || monto > saldo)
            throw new IllegalArgumentException("Fondos insuficientes o monto inválido");
        saldo -= monto;
    }

    public static void main(String[] args) {
        CuentaBancaria c = new CuentaBancaria(100);
        c.depositar(50);
        c.retirar(30);
        System.out.println("Saldo final: " + c.getSaldo());
    }
}

2) HERENCIA Y SOBRESCRITURA DE MÉTODOS
--------------------------------------------------------------
Nivel: Fácil–Media

ENUNCIADO:
Crea una clase base Empleado con un método pagoMensual().
Luego crea una subclase Comisionista que herede de Empleado y agregue un porcentaje de comisión sobre ventas.
Sobrescribe el método pagoMensual() para incluir la comisión.

CÓDIGO:
---------------------------------
class Empleado {
    protected String nombre;
    protected double sueldoBase;

    public Empleado(String nombre, double sueldoBase) {
        this.nombre = nombre;
        this.sueldoBase = sueldoBase;
    }

    public double pagoMensual() {
        return sueldoBase;
    }
}

class Comisionista extends Empleado {
    private double ventas;
    private double porcentaje;

    public Comisionista(String nombre, double sueldoBase, double ventas, double porcentaje) {
        super(nombre, sueldoBase);
        this.ventas = ventas;
        this.porcentaje = porcentaje;
    }

    @Override
    public double pagoMensual() {
        return sueldoBase + ventas * porcentaje;
    }

    public static void main(String[] args) {
        Empleado e = new Empleado("Ana", 1200);
        Comisionista c = new Comisionista("Luis", 900, 5000, 0.05);
        System.out.println(e.pagoMensual());
        System.out.println(c.pagoMensual());
    }
}

3) POLIMORFISMO CON INTERFAZ COMÚN
--------------------------------------------------------------
Nivel: Media

ENUNCIADO:
Diseña una interfaz Vehiculo con un método costoViaje(double km).
Implementa tres clases que la utilicen: Coche, Bici y Patinete.
Luego, crea una función que calcule el costo total de un viaje considerando una lista de vehículos distintos.

CÓDIGO:
---------------------------------
interface Vehiculo {
    double costoViaje(double km);
}

class Coche implements Vehiculo {
    public double costoViaje(double km) { return 0.12 * km; }
}

class Bici implements Vehiculo {
    public double costoViaje(double km) { return 0.01 * km; }
}

class Patinete implements Vehiculo {
    public double costoViaje(double km) { return 0.03 * km; }
}

public class Viaje {
    public static double costoTotal(Vehiculo[] vehiculos, double km) {
        double total = 0;
        for (Vehiculo v : vehiculos) total += v.costoViaje(km);
        return total;
    }

    public static void main(String[] args) {
        Vehiculo[] lista = { new Coche(), new Bici(), new Patinete() };
        System.out.println("Costo total del viaje: " + costoTotal(lista, 100));
    }
}

4) CLASES ABSTRACTAS Y ORDENAMIENTO
--------------------------------------------------------------
Nivel: Media–Alta

ENUNCIADO:
Crea una clase abstracta Forma con métodos area() y perimetro().
Implementa las subclases Rectangulo y Circulo.
Luego, crea una lista de formas y ordénalas por su área.

CÓDIGO:
---------------------------------
import java.util.*;
import java.lang.Math;

abstract class Forma {
    abstract double area();
    abstract double perimetro();
}

class Rectangulo extends Forma {
    private double w, h;
    public Rectangulo(double w, double h) { this.w = w; this.h = h; }
    double area() { return w * h; }
    double perimetro() { return 2 * (w + h); }
}

class Circulo extends Forma {
    private double r;
    public Circulo(double r) { this.r = r; }
    double area() { return Math.PI * r * r; }
    double perimetro() { return 2 * Math.PI * r; }
}

public class FormasDemo {
    public static void main(String[] args) {
        List<Forma> formas = Arrays.asList(
            new Rectangulo(2,3),
            new Circulo(1),
            new Rectangulo(1,10)
        );
        formas.sort(Comparator.comparingDouble(Forma::area));
        for (Forma f : formas)
            System.out.println(f.getClass().getSimpleName() + " - área: " + f.area());
    }
}

5) PATRÓN STRATEGY (COMPOSICIÓN)
--------------------------------------------------------------
Nivel: Alta

ENUNCIADO:
Crea una aplicación de Carrito de compras que utilice el patrón Strategy.
Debe permitir cambiar el método de pago entre PagoTarjeta y PagoPayPal dinámicamente.
Cada estrategia implementa una interfaz EstrategiaPago.

CÓDIGO:
---------------------------------
interface EstrategiaPago {
    String pagar(double monto);
}

class PagoTarjeta implements EstrategiaPago {
    private String numero;
    public PagoTarjeta(String numero) { this.numero = numero; }
    public String pagar(double monto) {
        return String.format("Cobrado %.2f con tarjeta ****%s", monto, numero.substring(numero.length()-4));
    }
}

class PagoPayPal implements EstrategiaPago {
    private String email;
    public PagoPayPal(String email) { this.email = email; }
    public String pagar(double monto) {
        return String.format("Cobrado %.2f vía PayPal (%s)", monto, email);
    }
}

class Carrito {
    private double[] items;
    private EstrategiaPago estrategia;

    public Carrito(double[] items, EstrategiaPago estrategia) {
        this.items = items;
        this.estrategia = estrategia;
    }

    public void setEstrategia(EstrategiaPago estrategia) {
        this.estrategia = estrategia;
    }

    public double total() {
        double t = 0;
        for (double x : items) t += x;
        return t;
    }

    public String checkout() {
        if (estrategia == null) throw new IllegalStateException("Sin estrategia de pago");
        return estrategia.pagar(total());
    }

    public static void main(String[] args) {
        Carrito c = new Carrito(new double[]{10,20,5}, new PagoTarjeta("1234567890123456"));
        System.out.println(c.checkout());
        c.setEstrategia(new PagoPayPal("user@mail.com"));
        System.out.println(c.checkout());
    }
}

6) PATRÓN OBSERVER (PUBLICAR–SUSCRIBIR)
--------------------------------------------------------------
Nivel: Alta

ENUNCIADO:
Implementa el patrón Observer con una clase Observable que notifique a varios Observer cuando un valor cambie.
Cada Observer debe reaccionar de forma diferente (por ejemplo, registrar el cambio o contar valores altos).

CÓDIGO:
---------------------------------
import java.util.*;

interface Observer {
    void update(int valor);
}

class LoggerObserver implements Observer {
    private List<String> logs = new ArrayList<>();
    public void update(int valor) {
        logs.add("Nuevo valor: " + valor);
    }
    public List<String> getLogs() { return logs; }
}

class ThresholdObserver implements Observer {
    private int umbral;
    private int disparos = 0;
    public ThresholdObserver(int umbral) { this.umbral = umbral; }
    public void update(int valor) {
        if (valor >= umbral) disparos++;
    }
    public int getDisparos() { return disparos; }
}

class Observable {
    private int valor;
    private Set<Observer> subs = new HashSet<>();

    public void subscribe(Observer o) { subs.add(o); }
    public void unsubscribe(Observer o) { subs.remove(o); }

    public void setValor(int valor) {
        this.valor = valor;
        for (Observer o : new HashSet<>(subs)) {
            o.update(valor);
        }
    }
}

public class ObserverDemo {
    public static void main(String[] args) {
        Observable o = new Observable();
        LoggerObserver log = new LoggerObserver();
        ThresholdObserver thr = new ThresholdObserver(5);
        o.subscribe(log);
        o.subscribe(thr);

        for (int v : new int[]{1, 3, 5, 7}) o.setValor(v);

        System.out.println("Logs: " + log.getLogs());
        System.out.println("Superó umbral: " + thr.getDisparos() + " veces");
    }
}
